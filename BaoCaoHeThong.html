Smart Attendance System — Xác thực thẻ Chip CCCD & Kiểm soát Anti-Passback

1. Kiến Trúc & Công Nghệ Cốt Lõi

Hệ thống được xây dựng trên mô hình phân tán (Distributed Architecture), tối ưu hóa luồng dữ liệu giữa thiết bị biên (Edge) và máy chủ trung tâm (Central Hub).

Backend & API

Java 21 Spring Boot 3.2 MySQL 8.0
  • Quản lý nghiệp vụ: Điều phối xác thực 2 lớp.
  • Bảo mật: JWT Stateless, RBAC 5 cấp độ.
  • Real-time: WebSocket STOMP đồng bộ Dashboard.

AI & Computer Vision

Python 3.10 ArcFace Flask
  • Mô hình: InsightFace (ResNet-100) đạt độ chính xác ~99%.
  • Processing: Trích xuất vector 512 chiều.
  • Optimization: ONNX Runtime cho triển khai CPU/GPU.

Client & IoT

Flutter 3.19 ESP32 MQTT
  • Mobile: Đọc Chip CCCD qua NFC (BAC/PACE).
  • Hardware: Điều khiển rơ-le khóa cửa qua MQTT SSL.
  • Offline-mode: SQLite lưu trữ bản ghi tạm khi mất mạng.

2. Luồng Nghiệp Vụ & Logic Kiểm Soát

Chu trình điểm danh chuẩn (Positive Flow)

1

Quét QR & Nhận diện Chip

Ứng dụng di động bóc tách số CCCD và mã CAN. Thực hiện "bắt tay" NFC để lấy ảnh chân dung gốc từ phân vùng DG2.

2

Xác thực 2 lớp (Dual-Auth)

Lớp 1: MobileFaceNet chạy offline trên điện thoại. Lớp 2: ArcFace chuyên sâu chạy trên AI Server trung tâm.

3

Kiểm tra Anti-Passback

Hệ thống truy vấn trạng thái gần nhất. Ngăn chặn nếu người dùng quét RA khi chưa có bản ghi VÀO trong ngày.

4

Kích hoạt chấp hành

Gửi lệnh MQTT lệnh OPEN_DOOR tới ESP32 và đẩy sự kiện WebSocket lên DashBoard quản trị mầu sắc (Xanh/Đỏ).

4. Anti-Passback & Self-Healing State Machine

Hệ thống triển khai một Máy trạng thái tự phục hồi để giải quyết bài toán "quên quét thẻ" hoặc "quét sai quy trình".

🚫 Anti-Passback

Phát hiện: Direction = OUT nhưng Last_Log != IN.
Hành động: Từ chối mở cửa, cảnh báo ANTI_PASSBACK.

🔄 Daily Session Reset

Tự động đóng các phiên "Quên quét ra" khi hết giờ làm việc dựa trên cấu hình end_time của từng nhân sự.

📊 Trạng thái chi tiết

Ghi nhận nhãn: SUCCESS, FAILED, MISSING_OUT, AUTO_CLOSED.

6. Hành Lang Bảo Mật (Security Layer)

OWASP #1

Broken Access Control

Sử dụng JWT ký số HS256. Mọi request được lọc qua JwtFilter. Phân quyền chặt chẽ tới từng Method API bằng @PreAuthorize.

OWASP #3

Injection Prevention

Tuyệt đối không sử dụng SQL thô. Sử dụng Spring Data JPA Parameterized Queries để chống SQL Injection 100%.

OWASP #7

Identification Issues

Khóa tài khoản khi nhập sai quá nhiều lần. Mã OTP xác thực email có thời hạn 10 phút và chỉ sử dụng một lần (nonce).
